File Format & Quality

Audio Specifications

All audio files must be delivered in the following format:

48 kHz / 24-bit WAV Final Master
✓
Deliver all files at final release level. All versions and stems must sound exactly like the main track, with your full mastering chain applied.

Project Code

For the Project Code, contact us at or@ainsof.io


Track Codes are based on the track order:

trk01 , trk02 , trk03 ...

Full Mix & Alts

File Naming

Project Code _ Track Code _ Track Name _ Version
Example:  AIN-ART 001_trk01_Come Get It_FullMix.wav
🎵
Required

Full Mix

Main version of the track — the complete, final mix.

🔇
Required

No Percussion

Version of the track without drums and percussion.

🎹
Required

No Melody

No main melodies and main elements of the track.

🎤
If Applicable

No Vocals

If the track has vocals, include an instrumental version.

🌏
Possible Extra

Music Bed

Version including only the pads, atmospheres, drones, and FX.

🔊
Possible Extra

Underscore

Without the main melody or lead melodies — a stripped-down, supportive version of the track.

4

Stems

File Naming

Project Code _ Track Code _ Track Name _ Stem Type
Example:  AIN-ART 001_trk01_Come Get It_Drums.wav

Required Stems

Grouped stems depending on the track & genre. We need the flexibility to create versions and play with the tracks. Include stems like:

High + Low Drums
High + Low Percussion
High + Low Synths
Strings
Brass
Woodwinds
FX & Risers
Hits
Guitars
Choir
Lead Vocals
Backing Vocals

+ Any stem that is relevant to the track.

✓
Make sure that if you put all the stems together on a separate project, the track sounds exactly like the full mix.
⚠
If the track has Side-Chain, please include the stems with the Side-Chain embedded.
